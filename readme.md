# LessPlay

LessPlay is a fun and interactive mini-game hub, featuring a collection of games built using pure HTML, CSS, and JavaScript. The games are designed to be engaging and fun for all ages.

## Features(till date)
- **Tic-Tac-Toe**
- **Simon Says**
- **Whack-a-mole**
- **Bouncing Balls**
- **Wordle**
- **Random Brain Teaser**

## Technologies Used
- HTML5
- CSS
- Vanilla JavaScript
- Gsap animations
